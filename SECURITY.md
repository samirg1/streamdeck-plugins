# Security Policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing vulnerability details, Jira site information, email addresses, API tokens, or other credentials.

Include the affected plugin and version, reproduction steps, expected impact, and any suggested remediation. You should receive an acknowledgement within seven days.

If a Jira API token may have been exposed, revoke it immediately through your Atlassian account rather than waiting for a software fix.
